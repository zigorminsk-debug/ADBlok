# ADBlok — блокировщик интернет-рекламы для Android

Приложение поднимает **локальный VPN** (трафик никуда не уходит, сервер не нужен) и фильтрует
DNS-запросы: домены рекламы и трекеров получают ответ `NXDOMAIN`, остальные запросы проксируются
к выбранному DNS-серверу. Работает во всех браузерах и приложениях сразу, root не требуется.

## Возможности

- Включение/выключение защиты одним переключателем (VpnService + foreground-сервис)
- Фильтрация по спискам: StevenBlack, AdAway, AdGuard DNS filter, AdGuard CNAME-трекеры, RU AdList (настраивается)
- Понимает формат hosts, «голые» домены и правила Adblock-синтаксиса `||domain^$third-party`
- Встроенный базовый список — работает сразу после установки, без интернета
- Блокировка поддоменов (`ads.example.com` блокируется правилом `example.com`)
- Белый список и собственные правила блокировки
- Выбор вышестоящего DNS: Cloudflare, Google, Quad9, AdGuard, Яндекс
- Статистика: заблокировано / пропущено / число правил
- Автозапуск защиты после перезагрузки устройства и после обновления приложения (отключаемо)
- Material 3 интерфейс, светлая и тёмная темы

## Структура

```
app/src/main/java/com/adblok/app/
├── data/BlocklistRepository.kt  — загрузка, парсинг и кэш списков, проверка доменов
├── data/Prefs.kt                — настройки и счётчики
├── vpn/AdVpnService.kt          — VpnService, цикл чтения TUN, фильтрация и форвардинг DNS
├── vpn/BootReceiver.kt          — автозапуск после BOOT_COMPLETED / обновления приложения
├── vpn/DnsPacket.kt             — разбор DNS-запроса и сборка NXDOMAIN
├── vpn/IpPacket.kt              — IPv4/UDP: парсинг и сборка ответа с контрольными суммами
└── ui/MainActivity.kt           — интерфейс
```

## Сборка локально

```bash
./gradlew assembleDebug      # или: gradle assembleDebug
```

Для релизной подписи: скопируйте `keystore.properties.example` → `keystore.properties`
и укажите путь к своему `.jks`.

## Автосборка в GitHub Actions

Workflow: `.github/workflows/android-build.yml`

- Запускается на каждый push, PR и вручную (`workflow_dispatch`).
- **Порядковый номер сборки** — `github.run_number`: он же `versionCode` APK,
  попадает в `versionName` (`1.0.N`), в имя файла `ADBlok-release-buildN.apk`,
  в имя артефакта и в тег релиза `build-N`.
- APK подписывается **постоянным ключом** из секретов репозитория; после сборки
  выполняется `apksigner verify --print-certs`, отпечаток сертификата виден в Summary —
  так легко убедиться, что ключ не менялся между сборками.

### Настройка постоянного ключа (делается один раз)

```bash
./scripts/generate-keystore.sh
```

Скрипт создаст `adblok-release.jks` (RSA 4096, срок 30 лет) и напечатает значения.
Добавьте их в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | base64 файла `adblok-release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `adblok` |
| `KEY_PASSWORD` | пароль ключа |

Храните `.jks` и пароли — только этот ключ позволит обновлять уже установленное приложение.
Если секреты не заданы, сборка не падает: APK подписывается отладочным ключом,
в лог выводится предупреждение.

## Автозапуск

Переключатель «Включать при запуске устройства» (по умолчанию включён) стартует фильтрацию
сразу после перезагрузки. Разрешение на VPN система запрашивает только один раз — поэтому
нужно хотя бы раз включить защиту вручную; после этого `VpnService.prepare()` возвращает `null`,
и сервис поднимается без участия пользователя. На прошивках с агрессивной экономией батареи
(Xiaomi, Huawei, Samsung) дополнительно разрешите приложению автозапуск в настройках системы.

## Ограничения

DNS-фильтрация работает по доменам и принципиально не может убрать рекламу, которую сайт
отдаёт со своего же домена: баннеры в вёрстке, вставки в ленте, «липкие» видео-плееры
вроде блока RELATED VIDEO на korrespondent.net. Их скрывают косметические правила (CSS),
а для этого нужен браузер с поддержкой расширений.

Что помогает на практике:

1. Нажать «Обновить списки» — в комплект входят AdGuard DNS filter и RU AdList,
   они закрывают большинство рекламных и видео-сетей рунета.
2. Если конкретный блок остался — посмотреть, с какого домена грузится виджет
   (в Chrome: меню → «Версия для ПК» → инспектор, либо по названию сети),
   и добавить домен в «Свои правила» в приложении.
3. Для косметической чистки страниц дополнительно использовать браузер с блокировщиком
   (Firefox + uBlock Origin, Brave, Cromite) — ADBlok при этом продолжает резать
   трекеры и рекламу во всех остальных приложениях.
